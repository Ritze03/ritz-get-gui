# ritz-get-gui

A Rust eframe/egui (egui 0.33) graphical front end for the `ritz-get` CLI. It only runs `ritz-get` commands, one at a time, and shows the result. Source in `src/`; tests include a fake CLI in `tests/fake-ritz-get`; see `README.md` for install and usage.
