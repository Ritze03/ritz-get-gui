# Changelog

All notable user-facing changes, newest first. Categories:

**Added** (new features),
**Fixed** (bug and behaviour fixes),
**Removed** (things taken out),
**Info** (notes worth knowing).

## 2026-11-11

### Fixed
- **Finding Ritz-Get**: the app now finds Ritz-Get even if it is not on your usual path.

## 2026-11-10

### Fixed
- **Icons for private programs**: icons now also show for programs in private
  repositories.

## 2026-11-07

### Fixed
- **Settings button**: the gear is now centred in its circle.

## 2026-11-04

### Fixed
- **Updating**: Update and Update all now ask for your password when it is needed.

## 2026-10-30

### Fixed
- **Freezing window**: fixed the window being reported as not responding.

## 2026-10-29

### Added
- **Background runs**: reopen a run that is working in the background, and stop it
  with a button.
- **Error reports**: a failed run offers to report it on GitHub or open its full log.
- **Deleted branches**: a warning shows when a program's branch was removed online.
- **App icon**: the top bar now shows the app icon.

### Fixed
- **Delete data**: you now confirm by typing the program's name.
- **Check for updates**: new branches show up without restarting.
- **Run window**: the short status now shows only the main steps.

## 2026-10-28

### Fixed
- **Branch choice**: picking a branch no longer installs or switches right away; Install
  and Update use your choice.
- **Installer**: it now works on systems with no default Rust setup.

## 2026-10-25

### Added
- **First release**: a graphical front end for Ritz-Get to install, update, remove and
  open programs.
- **Delete data**: remove a program's saved data from the app, with a confirmation.
- **Website icons**: icons for websites are fetched automatically.

### Fixed
- **Newer Ritz-Get**: the app no longer breaks on information it does not know yet.
